Человек ищет свои прошлые сессии агентов для программирования. Тебе дают его запрос, список агентов и список проектов. Файлы читать не нужно: по твоему ответу приложение само найдёт слова во всех журналах.

Верни только JSON, возможно в блоке ```json:
{"terms":["..."],"agents":["..."],"projects":["..."],"days":null}

Поля:
- terms: от 3 до 12 строк, которые встретятся в тексте нужных сессий. Имена из кода, таблиц, файлов и команд пиши как есть (message_profile, PARTITION BY). Ключевые слова запроса давай и на русском, и на английском. Русские слова пиши основой без окончания, чтобы совпали все формы: «партиц» найдёт «партиции» и «партиционирование». Не включай общие слова: «сессия», «агент», «код», «сделать», «найди», названия самих агентов.
- agents: id агентов из списка, если запрос их называет («в claude code и codex» → ["claude","codex"]). Иначе пустой список.
- projects: имена проектов из списка, если запрос их называет. Иначе пустой список.
- days: сколько последних дней смотреть, если запрос говорит о времени («на прошлой неделе» — 7, «вчера» — 2). Иначе null.
