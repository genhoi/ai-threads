# «Нить»: как устроен интерфейс

## Для кого и зачем

Разработчик ведёт несколько агентов для программирования сразу: Claude Code, Codex, Grok, Kimi,
Cursor Agent. Агенты работают в разных проектах и ветках, часто по два-три в одном репозитории.
Если каждый агент запущен в своей вкладке терминала, непонятно, кто из них закончил и ждёт ответа,
вкладки теряются, а старую сессию приходится искать по памяти.

«Нить» — одно место работы с агентами. Здесь их запускают, следят за ними, отвечают им, ищут старые
сессии и закрывают сделанные задачи, с компьютера и с телефона.

## Решения, на которых держится остальное

1. **Агент работает в своём настоящем терминале.** Справа открыт CLI агента, как в обычной вкладке.
   Все его команды, запросы разрешений и режимы работают без изменений. «Нить» добавляет вокруг
   терминала запуск, состояние, поиск и сводки. Агент живёт в tmux и продолжает работать, если
   закрыть страницу или перезапустить «Нить».
2. **Где работает агент, выбирают при запуске.** Есть два варианта: папка проекта или отдельная копия
   репозитория (git worktree), то есть своя папка со своей веткой. Копия нужна, когда в одном
   репозитории параллельно работают несколько агентов: так они не правят одни и те же файлы.
3. **«Нитью» пользуются и с телефона.** С телефона видно, кто ждёт ответа, на чём остановился агент,
   и можно ему ответить или запустить новую сессию.
4. **Сессии, начатые вне «Нити», тоже видны.** «Нить» читает журналы агентов, поэтому такие сессии
   можно найти и продолжить здесь. Сессии ZCode только видны: продолжить их можно в приложении ZCode.

## Понятия

- **Проект** — папка репозитория. «Нить» собирает проекты из папок сессий. Новый проект появляется,
  когда в его папке запускают первую сессию: в окне запуска есть «Другая папка…».
- **Сессия** — один разговор с агентом. У сессии есть агент, проект, ветка, название и журнал,
  который ведёт сам агент.
- **Копия** — git worktree проекта, созданная для одной сессии: отдельная папка и ветка.
- **Служебные сессии** — автоматические запуски, которые обычно делают другие агенты для ревью
  и сводок (`codex exec`, `claude -p`, `grok -p`, `kimi -p`), и сессии во временных папках
  (`/tmp`, `/var/tmp`, `~/.local`). Они скрыты из списков, их показывает фильтр «Служебные».
  Признаки меняются в настройках.

## Состояния сессии

| Состояние | Что значит | Цвет |
|---|---|---|
| запускается | терминал открыт, агент ещё ничего не вывел | серый |
| работает | агент выполняет задачу | зелёный |
| ждёт вас | агент закончил ход или спрашивает разрешение | янтарный |
| завершился | процесс агента вышел без ошибки | серый |
| ошибка · код N | процесс агента вышел с ошибкой | красный |
| в истории | терминала нет, сессию можно продолжить | без отметки |

К состоянию «ждёт вас» добавляется отметка **«новое»**: агент закончил ход, пока человек не смотрел
на эту сессию. В «Ждут вас» новые стоят первыми, дальше — кто дольше ждёт. Счётчик ожидающих
считает все ждущие и упавшие сессии.

Откуда «Нить» берёт состояние. Claude Code сам сообщает, работает он или ждёт, в том числе когда
запущен в другом терминале. Grok сообщает только, что процесс жив, остальные агенты не сообщают
ничего. Для сессий в терминалах «Нити» состояние определяется по экрану: пока агент работает, экран
меняется; экран замер на 2,5 секунды — агент ждёт.

## Сценарии

### 1. Начать задачу

Пришла задача BACKEND-10300. Её должен сделать Claude Code в репозитории backend, где уже работает
другой агент.

1. «Новая сессия»: клавиша N, кнопка вверху панели или «+» у проекта.
2. Проект: недавние сверху, поиск по имени, «Другая папка…» для любой папки.
3. Агент: только установленные и включённые. По умолчанию — агент по умолчанию проекта или тот,
   кого запускали в проекте последним. Рядом модель и уровень рассуждений, по умолчанию — как
   настроено в CLI агента.
4. Где работать: «Папка проекта» или «Копия» с новой веткой. Имя ветки предлагается из запроса,
   например `BACKEND-10300`. Если в папке проекта уже работает другой агент, «Нить» предлагает копию
   и пишет почему.
5. Первый запрос, необязательный. Сюда вставляют текст задачи.
6. «Запустить» или Ctrl+Enter.

Агент открывается в терминале справа. Сессия появляется в панели под своим проектом, сначала
в состоянии «запускается», потом «работает». Пока агент не дал сессии название, она называется
по первому запросу. Если tmux или агенты не установлены, вместо окна запуска открывается экран
первого запуска с командами установки.

### 2. Разобрать ожидающих

Запущено шесть агентов в четырёх проектах. Трое закончили и ждут ответа.

- Число ожидающих видно в панели и в заголовке вкладки браузера: «(3) Нить».
- Раздел «Ждут вас» вверху панели. В строке — последняя фраза агента, обычно это вопрос, и сколько
  он ждёт. Сразу видно пять строк, остальные — под «ещё N».
- Alt+↓ открывает следующую ждущую сессию. Сочетание работает и тогда, когда фокус в терминале.
- Пока страница открыта, о новой ждущей или упавшей сессии сообщает всплывающее окно с кнопкой
  «Открыть». Если эта сессия уже открыта на экране, окна нет.

### 3. Следить за работающими

Агент делает долгую задачу, человек занят другим.

- Раздел «Работают» в панели: сколько времени агент работает и последняя строка его вывода.
- Агент завершился с ошибкой — сессия поднимается в «Ждут вас» с отметкой «ошибка · код N».

### 4. Вернуться к старой задаче

Через неделю нужно продолжить BACKEND-10281.

1. Поиск (Ctrl+K или значок лупы в панели): по названию, ветке, задаче и пути. Переключатели
   добавляют поиск по переписке и служебные сессии.
2. Если быстрый поиск ничего не нашёл, «Искать во всех журналах» ищет точное совпадение в полных
   журналах всех сессий.
3. Другой путь — «История» (клавиша H): все сессии по дням, фильтры по проекту и агенту.
4. Сессия без терминала открывается карточкой: сводка, следующий шаг, переписка и кнопка
   «Продолжить в терминале».

### 5. Продолжить сессию, начатую вне «Нити»

Человек запустил `claude` в обычном терминале, а теперь хочет вести эту сессию в «Нити».

- Такие сессии видны в списках, как все остальные.
- Если агент ещё работает с сессией в другом терминале или в фоне, «Нить» говорит об этом и второй
  раз его не запускает. Это видно у Claude Code и Grok: остальные агенты не сообщают, что запущены.
- Иначе — «Продолжить в терминале», и дальше сессия живёт в «Нити».

### 6. Ещё один агент в той же копии

Claude закончил, а изменения должен проверить Codex в той же копии. В меню проекта «Копии проекта»
выбирают копию: открывается окно запуска с этой папкой, остаётся выбрать агента и написать запрос.

### 7. Завершить задачу

Ветка влита. В меню сессии «Завершить…» открывает окно со списком того, что произойдёт:

- агент остановится, терминал закроется;
- сессия отметится завершённой и останется в проекте и поиске;
- копия удалится; ветка удалится, если git это разрешает, иначе останется.

Копию «Нить» не удаляет, если в ней есть незакоммиченные файлы, ветка никуда не отправлена или
в копии работает другой агент, и говорит почему. Пока копия не удалена, завершение можно отменить:
«Вернуть из завершённых» в меню сессии.

### 8. Ответить с телефона

Человек отошёл от компьютера, а агент спрашивает разрешение выполнить команду.

1. На телефоне открыт список: «Ждут вас», «Работают», «Проекты».
2. Сессия показывается экраном терминала текстом с переносом строк.
3. Ответ: поле ввода и ряд быстрых клавиш: 1, 2, 3, Enter, Esc, Ctrl+C, стрелки вверх и вниз.
   Этого хватает, чтобы ответить на запрос разрешения у любого агента.
4. Агент продолжает работу, сессия уходит из «Ждут вас».

С телефона также можно найти сессию, открыть сессии проекта и запустить новую. Подключение:
на компьютере «Настройки» → «Доступ с телефона» показывает QR-код со ссылкой и ключом.

### 9. После перезагрузки компьютера

Компьютер перезагрузился, агенты в tmux остановились. «Нить» показывает, какие сессии были открыты,
и продолжает все или выбранные. Невыбранные остаются в проектах и истории.

### 10. Итоги за несколько дней

Нужно вспомнить, что сделано за несколько дней и что осталось. Страница «Сводка»: период 3 дня,
5 дней или неделя. Агент читает журналы сессий за эти дни и пишет итоги по проектам со ссылками
на сессии. Кто пишет, выбирают там же. Сводку по одной сессии составляют в её сведениях.

### 11. Порядок в списке

Сессию можно переименовать, закрепить, скрыть, отметить завершённой. Служебные сессии скрыты,
фильтр их показывает. Проект можно закрепить или скрыть, у проекта можно задать агента по умолчанию.

## Устройство экрана

### Широкое окно

**Панель слева.** Её можно спрятать целиком (Ctrl+B или кнопка вверху), тогда терминал занимает всю
ширину.

1. Вверху: «Новая сессия», поиск, кнопка, которая прячет панель.
2. «Ждут вас» и «Работают» с числом сессий. Пустой раздел не показывается.
3. «Проекты»: закреплённые, потом недавние. Внутри проекта — его сессии: сначала открытые,
   потом несколько последних и «ещё N». У проекта «+» (новая сессия в нём) и меню «⋯»:
   путь, новая сессия, открыть в VS Code или папку, копии проекта, агент по умолчанию, закрепить,
   скрыть.
4. Внизу: «История», «Сводка» и значок настроек. Адрес сервера, доступ с телефона, выгрузка
   и загрузка данных — в настройках.

Пока курсор над панелью, строки не переставляются и не появляются: щелчок попадает туда, куда
целились. Новые строки приходят, когда курсор уйдёт.

**Справа — выбранная сессия.**

- Заголовок в одну строку: иконка агента, название, проект и ветка (у копии — плашка «копия»),
  состояние, «Во весь экран» и меню «⋯». Длинное название обрезается многоточием, полный текст
  в подсказке.
- Меню «⋯»: сведения, переименовать, закрепить, скрыть, открыть в VS Code или папку, команда для
  своего терминала, следующая ждущая, завершить.
- Терминал занимает всё остальное место.
- Щелчок по названию открывает «Сведения о сессии» — панель поверх терминала: сводка и следующий
  шаг, переписка, команда для подключения из другого терминала, с какими настройками запущена.
- Сессия в истории, без терминала: карточка со сводкой, перепиской и кнопкой «Продолжить в терминале».

**Главная, когда сессия не выбрана** — окно новой сессии: большое поле «Что сделать?», под ним
проект, агент, модель, рассуждения и выбор «Папка проекта / Копия». Ниже — ожидающие и недавние
проекты.

**Отдельные страницы:** «История», «Сводка», «Настройки» (агенты, сводка, служебные сессии, tmux,
доступ с телефона, данные, сочетания клавиш, о приложении), экран после перезагрузки и экран
первого запуска.

### Телефон и узкое окно

При ширине до 600 px «Нить» переходит на вёрстку для телефона.

- Список: «Ждут вас», «Работают», «Проекты», поиск, кнопка новой сессии.
- Сессия: вывод терминала текстом с переносом строк, поле ответа и быстрые клавиши. Телефон
  не меняет размер терминала: агент на компьютере продолжает видеть широкий экран.
- Новая сессия: те же поля, что на компьютере.
- Проект: его сессии по дням.

### Клавиатура

| Клавиши | Что делают |
|---|---|
| N | новая сессия |
| Ctrl+K | поиск |
| Alt+↓ | следующая ждущая сессия, работает и из терминала |
| Ctrl+B | спрятать или показать панель |
| H | история |
| Ctrl+Enter | запустить в окне запуска |
| Esc | закрыть поиск или сведения о сессии |

Пока фокус в поле ввода, сочетания не работают. В терминале клавиши уходят агенту, кроме Alt+↓.
Ctrl+W, Ctrl+T и Ctrl+N браузер оставляет себе, поэтому «Нить» их не использует.

## Мелочи, которые решают удобство

- Обновление состояний ничего не сдвигает под курсором: щелчок попадает туда, куда целились.
- Терминал меняет размер без анимации: каждое изменение размера перерисовывает экран агента.
- Пустые состояния: нет ни одного агента, нет tmux, нет проектов, ничего не найдено.
- Каждая кнопка-иконка с подписью в подсказке, всё доступно с клавиатуры.
