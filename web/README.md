# Интерфейс «Нити»

TypeScript и Preact. esbuild собирает `src/` в `dist/`, а `embed.go` вшивает `dist/` в бинарник `nit`.

## Команды

Node 24 или новее и npm. Один раз: `npm ci`. `npm run fonts` читает `src/icons.ts` напрямую, поэтому
Node нужен такой, который сам убирает типы TypeScript.

| Команда | Что делает |
|---|---|
| `npm run build` | сборка в `dist/`: сжатые `app.js` и `app.css`; xterm с дополнениями, галерея, макетные данные и общие куски — отдельными файлами в `dist/chunks/` |
| `npm run dev` | пересборка при изменениях в `.dev/` и сервер на http://127.0.0.1:5180, страница перезагружается сама |
| `npm run typecheck` | проверка типов (`tsc --noEmit`) |
| `npm run fonts` | заново скачать шрифты в `public/fonts/` |

## Почему `dist/` в git

`go install github.com/genhoi/ai-threads/cmd/nit@latest` собирает бинарник из исходников без Node,
поэтому собранный интерфейс должен лежать в репозитории. После изменений в `src/` или `public/`
нужно выполнить `npm run build` и закоммитить `dist/` вместе с кодом. Сборка повторяема: те же
исходники и `package-lock.json` дают те же файлы.

## Где что

- `src/styles/tokens.css` — цвета, шрифты, радиусы, тени, отступы и длительности из листа «Основы».
- `src/components/` — компоненты; стиль каждого лежит рядом и подключён в `src/styles/components.css`.
  Новый компонент нужно добавить и туда, иначе его стиль не попадёт в `app.css`.
- `src/model.ts` — агенты и состояния сессии, те же, что в `internal/model`.
- `src/api/` — типы API (те же, что в `internal/server/api.go`), запросы и поиск. Запросы, поток событий
  и терминал идут через `transport.ts`, поэтому их можно подменить.
- `src/app/` — состояние приложения, адрес экрана (`#/`, `#/s/<ключ>`, `#/history?project=&agent=&service=1`,
  `#/summary?days=5`, `#/settings`, `#/new`), поток событий, действия с сессиями, меню и сочетания клавиш.
  Задания сводок и сводки за период — `jobs.ts`, кто их пишет — `runners.ts`.
- `src/screens/` — экраны компьютера: панель, главная с окном запуска, сессия с терминалом, сведения, поиск,
  «Завершить задачу?» (стили — `src/styles/screens.css`); история, сводка, после перезагрузки, первый запуск,
  настройки и «Этот телефон отключён» (стили — `src/styles/pages.css`). Ход и ошибка задания сводки —
  `JobStatus.tsx`, доступ с телефона в настройках — `SettingsPhone.tsx`. Окно запуска без вида — `useLaunch.ts`,
  его делят главная и телефон.
- `src/lib/markup.tsx` — разметка текста сводок: только `` `код` ``, `**жирный**` и `[текст](ключ сессии)`,
  остальное выводится текстом.
- `src/phone/` — телефон и узкое окно до 600 px: список, сессия (экран терминала текстом, быстрые клавиши,
  ответ), новая сессия, сессии проекта. Стили — `src/styles/phone.css`. xterm на телефоне не грузится.
- `src/gallery/` — все компоненты во всех состояниях, открывается по адресу `/#gallery`.
- `src/mock/` — данные из макетов для работы без сервера, см. ниже.
- `public/` — `index.html` и шрифты, копируются в `dist/` как есть.

## Без сервера

С `?mock` в адресе интерфейс работает без «Нити»: запросы, поток событий и терминал отвечают из
`src/mock/` на данных из макетов. Режимы через запятую:

| Режим | Что показывает |
|---|---|
| `still` | часы стоят на 10:00, чтобы снимки экранов совпадали с макетом |
| `reboot` | экран после перезагрузки |
| `empty` | первый запуск без tmux и агентов |
| `agents-off` | агенты установлены, но все выключены в настройках |
| `digest-none` | сводок за период ещё нет (по умолчанию за 3 дня — статья из макета, за неделю — сводка первой версии) |
| `digest-running`, `digest-failed` | сводка за 3 дня составляется или не составилась |
| `summary-running`, `summary-failed` | то же для сводки по сессии BACKEND-10300 |
| `remote-off`, `remote-login`, `remote-cert`, `remote-running`, `remote-error` | доступ с телефона: выключен, ждёт входа в Tailscale, выпускает сертификат, работает с двумя телефонами, ошибка |
| `phone-remote` | страница открыта с телефона через Tailscale |
| `revoked` | то же, и через 0,4 с телефон отключают |
| `nocursor` | история без заголовков `X-Total-Count` и `X-Next-Cursor`: проверка, что интерфейс обходится без них |

Например, `?mock=still,remote-running`. Код `src/mock/` грузится отдельным файлом и только с `?mock`.
Пример: `npm run dev`, затем http://127.0.0.1:5180/?mock#/. Из консоли можно менять сессии:
`nitMock.wait(ключ)` — сессия ждёт, `nitMock.work(ключ)` — работает, `nitMock.fail(ключ)` — упала;
`nitMock.install()` в режиме `empty` «ставит» tmux и агентов для «Проверить снова». Для сводок и телефона:
`nitMock.failNext()` — следующее задание сводки закончится ошибкой, `nitMock.setDigest(сводка)` — своя сводка
за период, `nitMock.remote(состояние)` — доступ с телефона в другом состоянии, `nitMock.login()` — «вошли»
в Tailscale, `nitMock.revoke()` — отключить этот телефон. Для скриптов проверки: `nitMock.add(сессия)`
и `nitMock.patch(ключ, поля)` — добавить или поменять сессию, `nitMock.notice(вид, текст)` — всплывающее
сообщение, `nitMock.stats()` — сколько было запросов и потоков событий, `nitMock.world()` — все данные.

## Терминал

xterm.js рисует через WebGL (`@xterm/addon-webgl`): так линии и рамки псевдографики идут без разрывов
при строке 17 px. WebGL включается, только если его считает видеокарта. Без видеокарты браузер считает
WebGL на процессоре (SwiftShader, llvmpipe), и терминал занимает почти всё время страницы. Тогда, как и
без WebGL или при потерянном контексте, xterm рисует через DOM, а рамки выходят с разрывами.

Терминалы пяти сессий, открытых последними, остаются подключены, но скрыты (`TERMINALS_KEPT`
в `src/screens/Session.tsx`). Переход к такой сессии не создаёт xterm заново и не ждёт сервер. Скрытый
xterm принимает вывод, но не рисует. Терминал, закрытый на сервере, отпускается сразу, а уход с экрана
сессии на главную, в историю или настройки отпускает все.

Новый терминал подключается к серверу, пока xterm ещё создаётся, если лист терминала того же размера,
что у прошлого: число столбцов и строк тогда уже известно. xterm и JetBrains Mono грузятся заранее,
когда браузер свободен. Пока край окна тянут, размер терминала не меняется: новый уходит агенту, когда
край стоит 150 мс, потому что каждое изменение размера перерисовывает экран агента целиком.

## Шрифты и иконки

Manrope и JetBrains Mono (латиница и кириллица) и Material Symbols Outlined лежат в `public/fonts/`
вместе с лицензиями, интерфейс работает без сети. Из Material Symbols в шрифте только иконки из
`src/icons.ts`. Чтобы добавить иконку, впишите имя в `src/icons.ts` и выполните `npm run fonts`.
